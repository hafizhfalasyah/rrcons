## 📌 Overview

**RRCONS (Rita Russo Consultant)** is a web-based company profile platform designed to establish a strong digital presence while providing flexible content management capabilities.

The system is built to allow administrators to dynamically manage website content, including text, images, and multilingual support. It also incorporates SEO optimization features to enhance online visibility and reach.

This project demonstrates the implementation of a scalable CMS-driven architecture combined with multilingual support and SEO-friendly design, making it suitable for professional business use.

---

## 🎯 Key Highlights

- Company profile website with CMS capabilities  
- Fully customizable content (text & images)  
- Multilingual support (English & Indonesian)  
- SEO-friendly structure and optimization  
- Role-based user management system

## ✨ Features

- 🔐 Authentication System (Admin & User)

- 📝 Dynamic CMS (Content Management System)
